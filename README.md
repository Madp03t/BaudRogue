# BaudRogue

BaudRogue is a native macOS SSH terminal for connecting to bulletin board systems (BBSs), servers, and other SSH-enabled devices.

Built for Apple Silicon using Swift and SwiftUI, BaudRogue brings together the character of classic BBS terminals and the flexibility of modern SSH access.

The project began with a desire for a straightforward terminal that displays ANSI artwork correctly, respects traditional BBS layouts, and provides a comfortable interface for everyday SSH connections.

BaudRogue is **SSH-only**. Telnet support is intentionally excluded.

Privacy and simplicity are central to the project. Connection information is stored locally, with no accounts, subscriptions, or telemetry.

BaudRogue is currently at **version 0.1.0** and is under active development.

## Features

- ANSI graphics and CP437 support
- Fixed 80×24 BBS display with automatic scaling
- Automatic terminal sizing and UTF-8 support
- Adjustable SSH font sizes
- SSH host-key verification
- Connection library with favorites, search, and sorting
- JSON import and export
- Live connection status and terminal dimensions
